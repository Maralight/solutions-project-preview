## Important placeholders
Anything marked with `*`, `—`, `***`, placeholder contact details, certification labels and sector claims must be verified with the client before production.

## Forms
Contact and RFQ forms are preview-only. They show a local success state but do not transmit data. Connect them to an approved backend/email service before production.

## Hero media
The current preview uses local animated-style SVG industrial artwork for speed and portability. For production, replace the hero artwork with a licensed, compressed cinematic MP4/WebM loop on desktop and keep a static fallback on mobile/reduced-motion devices.

## Brand
The SP mark was extracted from the supplied client letterhead for preview use. Replace with the client's approved SVG/transparent master logo asset at handoff.
