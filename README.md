# Solutions Project Nigeria Ltd — Preview v2.0

This preview is intentionally **noindex**.

## Hero video
Place BOTH files in `assets/video/` using these exact names:
- `hero-desktop.webm`
- `hero-desktop.mp4`

WebM is attempted first, MP4 is fallback. If neither loads, `hero-poster.svg` displays automatically. Mobile uses the poster by default.

## Before production
Remove noindex, replace preview robots.txt, update sitemap to the client domain, connect Formspree, add GA4/Search Console, validate legal pages and confirmed credentials.
