# Image Replacement Guide

Replace the existing `.webp` file with a new image using the **same filename**. No HTML/CSS edit is required for normal image changes. Keep roughly the same aspect ratio and export as WebP.

## Homepage
- Hero slides: `assets/images/home/hero-slideshow/slide-01.webp` through `slide-06.webp`
- Service Bento: `assets/images/home/bento/`
- Sector imagery: `assets/images/home/sectors/`
- How We Work: `assets/images/home/how-we-work/`

## Service detail pages
Each service has `hero/`, `process/`, and `scope/` folders under `assets/images/service-pages/<service-name>/`.

## Homepage slideshow
The slideshow list is in `assets/js/config.js`. Add, remove, or reorder image paths in the `slides` array.
