HERO FALLBACK LOGIC
1. Desktop tries hero-desktop.webm first.
2. If unavailable, the browser tries hero-desktop.mp4.
3. If no playable video is found, the 4-scene cinematic slideshow remains visible.
4. If imagery cannot load, the underlying dark hero background remains.
5. Tablet and mobile deliberately use the slideshow instead of the video.

SLIDESHOW
The package contains four lightweight designed placeholder scenes:
- port / vessel / container crane
- engineering and construction environment with African PPE-clad personnel
- industrial equipment / heavy machinery
- inspection / technical environment with African PPE-clad personnel

For production, these placeholders should be replaced by licensed or approved high-quality photographic WebP/JPEG assets using the same filenames or by updating the CSS.
